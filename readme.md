# Learning FastAPI

In this repo I intend to dive into the intricacies of FastApi framework, while following along
to [Corey Schafer's](https://youtube.com) guide.

Core technologies learnt:
- Backend: FastApi
- Database: ORM(SQLAlchemy), Sqlite & PostgreSql
- Pydantic Models for data validation
- Authentication & Authorization: password hasing, JWT tokens
- Background Services: file uploads, password auth
- Asynchronous application: async & await
- Testing and deployment: pytest & docker
